# テトリス raylib

## ソースコード

- main.cpp: メイン処理
- game.cpp: ゲーム進行管理
- block.cpp: ブロック処理-
- blocks.cpp: ブロックの種類に関する処理
- grid.cpp: 盤面の管理
- position.cpp: 座標に関する処理
- colors.cpp: 色の管理

## 制作を通して学んだこと

ブロックの移動や回転、当たり判定など複数の処理を正しく、実装する難しさを実感しました。
また、ブロック、盤面、ゲーム進行などの機能をファイルごとに分割することで、それぞれの役割を明確にし、
プログラムを管理しやすくすることの大切さを学びました。
今回の経験を通して、ゲームを完成させるだけでなく、処理の仕組みやプログラムの構造を理解しながら開発することの重要性を感じました。
